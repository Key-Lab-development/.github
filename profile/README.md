# Key Lab

**Software engineering studio in Medellín, Colombia.** We build AI agents, automations, asset tokenization and custom software around each company's processes.

*Estudio de ingeniería de software en Medellín, Colombia. Construimos agentes de IA, automatizaciones, tokenización de activos y software a la medida alrededor de los procesos de cada empresa.*

## What we build

- **AI agents and RAG systems**, including WhatsApp agents on the official Meta API
- **Process automation** in TypeScript and Python
- **Real-world asset (RWA) tokenization** and smart contracts on EVM networks
- **Custom web, SaaS and Web3 platforms**
- **Video games and 3D experiences**

## Stack

TypeScript, NestJS, Next.js, PostgreSQL, Supabase, Railway, Solidity, Thirdweb, Python.
